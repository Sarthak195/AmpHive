# Headscale Project Context

## System Overview
Headscale is a self-hosted, open-source coordination server for Tailscale networks. It manages WireGuard public keys, NAT traversal STUN/DERP instructions, client IP allocations, namespaces (Users), and routing configurations. This enables users to operate encrypted overlay networks securely on their own private servers without cloud dependencies.

## Architecture & Tech Stack
- **Backend Language**: Go (Golang).
- **Security & Crypto**: Noise protocol implementations over HTTP for node coordination; WireGuard for peer-to-peer data plane tunneling.
- **Protobuf / API**: Buf-based protobuf definitions and gRPC service descriptors.
- **ORM & Database**: GORM layer wrapping SQLite (default) and PostgreSQL database engines.
- **Client Configuration**: Parses standard Tailscale `MapRequest` profiles and returns encrypted client maps (`MapResponse`).

## Core Domain Models
- **Users**: Defines logical tenant namespaces. Nodes and authorization policies are nested within a User boundary.
- **Nodes**: Represents the physical client devices connected to the Tailnet, including host specs, IP allocations, keys, and status.
- **PreAuthKeys**: Reusable or one-time keys generated by administrators to automate node registration without browser-based login flows.
- **APIKeys**: Administrative keys for authenticating integrations or CLI binaries calling the gRPC API.
- **Policies**: System configurations controlling connection limits and ACL boundary routes.

## Key Mechanisms
1. **Noise Handshakes**: Node registration and coordination requests pass through a custom cryptographic layer (`hscontrol/noise.go`), preventing MITM eavesdropping on network configurations.
2. **Long Polling Map Coordination**: Pushes updates to peers dynamically using long-lived TCP requests (`hscontrol/poll.go`), enabling instantaneous mesh updates when peer statuses change.
3. **Subnet Routing & Exit Nodes**: Handles routing rules allowing nodes to act as gateways or internet exit nodes, approved via CLI commands.

## Directory Structure
- `/hscontrol`: The core server daemon code.
  - `app.go`: Database initiation, routing, and configurations.
  - `noise.go`: Tailscale Noise protocol handler.
  - `poll.go`: Long polling and MapResponse updates.
  - `/db`: Database models and schemas (`schema.sql`).
- `/cmd`: Command-line tools.
  - `/headscale`: Main executable CLI package wrapping gRPC client APIs.
- `/proto`: Protobuf specifications defining API messages and gRPC services.
- `/gen`: Generated Go files compiled from the Proto specs.
- `/docs`: Documentation source markdown files.
- `config-example.yaml`: Complete list of configuration variables and defaults.
